# Files carrying a line-continued string literal, as a ceiling rather than an allowance.
#
# `\` at the end of a line inside a string literal is collapsed by `cargo fmt`, which bakes
# the source indentation into the rendered text - so a message written to read as a sentence
# arrives with runs of spaces through the middle of it. It has shipped garbled output three
# times, always at format time rather than when the line was written (D184).
#
# The replacement is `concat!` of one-line literals. Note that `concat!` defeats implicit
# `{name}` capture, so arguments go positional.
#
# `./orbistoun.sh prose` fails on any file here that is *not* listed, and fails again on any
# entry listed that has stopped offending. So this list can only shrink, and it cannot
# quietly become permanent by being ignored - the same mechanism the duplicate decision
# numbers use (D201).
#
# **It went 8 -> 21 once, which is the one direction the paragraph above forbids.** The
# guard was blind twice over: it searched the index rather than the working tree, and this
# repository has no commits; and then the expression meant to normalise its output aborted,
# emptying the offender list entirely. Both failures reported "none added". Twenty-one is
# the first count taken with the guard able to see, and it is the ceiling from here (D199).
#
