# D041 - Firmware / system-menu launch is the lowest-priority stretch goal

**decided** · 2026-08-19

Booting the vendor system menu, on the Dolphin precedent - Dolphin boots the Wii
System Menu from *the user's own NAND dump* and ships nothing itself.

**This does not weaken "no firmware required."** orbistoun never ships or requires
firmware; it would be required by the user only for this one optional feature.
Recorded explicitly so the greyed-out menu item is not later read as contradicting
the README's first bullet, and so nobody changes architecture over it.

Lowest priority of anything on any list. Completeness only, assuming the project
succeeds at some level first.
