# D660 - Generated title pages

**Status:** assumed
**Date:** 2026-09-09

Each title's page is generated from its compatibility record and the `sce_sys/param.json` it
ships, with the localised name shown beside the identifier. Every row renders whether or not it has
content: a title with no metadata file says so once, and a missing capture shows a shared
placeholder image.

**Why:** a hand-written page drifts the first time a run is recorded and nobody edits the prose,
which is the drift the record's measured half exists to prevent. The identifier stays because every
other artefact keys on it. A page that omits what it lacks cannot be told from one never finished.

**Rejected:**
- A template and a hand-written page per title: stale on the next run and unfalsifiable.
- Names replacing identifiers: the table could not be read against traces or records.
- Dropping empty rows: reads as though the question was never asked.
