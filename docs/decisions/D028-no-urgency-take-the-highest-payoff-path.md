# D028 - No urgency; take the highest-payoff path

**decided** · 2026-08-19

This is a personal proof of concept. There is no delivery pressure and no deadline.
Where two paths differ, take the one with the better end state. **A shortcut that
constrains the design is never worth the time it saves.**

Recorded as a decision rather than a mood because it is exactly the guidance a long
unattended run drifts away from - "simplest thing that works" is the default failure
mode. D032 is a live example: the first recommendation there was the shortcut, and
reconsidering under this directive reversed it.
